Three plans were graded needs-changes on execution defects rather than premise (006: missed a fourth constructor call site and a stale pinned test; 007: the settings move silently breaks "Clear Lasso data" — **still unfixed, see below**; 010: unsatisfiable done criteria, fixed by [plan 000](../review/000-harden-the-verification-harness.md)).

- *"Every drift check is inert because HEAD never moves."* HEAD moved: `7ce587e..HEAD` is 12 commits. The checks fire; an empty result is a correct "no drift". Leave `..HEAD` alone.
