1

Select-tap

Now ignores untrusted, synthetic, and non-primary clicks. It resolves the outermost tweet.

Why: Lasso drivers click inside tweets. Select mode could toggle and suppress the driver. Quoted tweets could pick the inner author.

Effect: no self-intercept, no wrong-author tap, fewer false Retry toasts.

2

Undo

Removals are paced, stop on rate-limit, carry observedAt, and cannot overlap an active assign.

Why: adds were paced; removes were not. Toast Undo could overlap a run. Toast died at 4s while undo lived 10s.

Effect: undo follows the same policy as assign. Less rate-limit risk. No invisible undo.

3

Chrome floor

Replaced toSorted, toReversed, and URL.canParse.

Why: the manifest says Chrome 106. Those APIs need newer Chrome.

Effect: no runtime TypeError on Chrome 106-119. Chrome 150+ still works.

4

Settings storage

Settings moved to chrome.storage.local. Legacy sync migrates once. Explicit Mirror clear stores null.

Why: the Mirror device key should not replicate through sync. A cleared dev credential must not refill from defaults.

Effect: better privacy. Local-first claim matches behavior. Explicit opt-out sticks.

Why this is a real quality jump

Not style-only. It removes four failure classes: driver self-block, wrong-author selection, unpaced undo mutations, and old-Chrome runtime crashes. It also moves the one long-lived credential out of sync storage. Tests now pin the behavior.

Residual risk: lint still warns about sort/reverse. That is intentional for Chrome 106. Remaining gaps: Mirror retry/GC, filter preset quota, hidden-post selection gate, unmute failure copy, GraphQL feature flags, PR #14/#15 need rework rather than merge.
